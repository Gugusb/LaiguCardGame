## 二、完整文件清单（包 · 文件 = 职责）

### 根（mod 入口）
- `Laigu` = 主类（构造注册 ModPackets / ModCapabilities 监听）。

### album（收藏册数据）
- `CollectionAlbumData`、`AlbumPages` = 收藏册分页/数据。

### block（方块）
- `CardExchangeTableBlock(+Entity)` = 卡牌交换台（A/B 侧、trySwap、tryReset、releaseSide）。
- `DuelTableBlock(+Entity)` = 对战方块（登记/AI/离房/观战/黑暗对决/破坏兜底）。

### buff / capability / card / util（收集侧）
- `buff/CardSynergy` = 副手卡袋羁绊 6 规则。
- `capability/IPlayerCodex / PlayerCodex / PlayerCodexProvider / ModCapabilities` = 玩家图鉴 Capability。
- `card/CardCatalog` = 79 卡 id 清单；`card/CardInfo` = 朝代/类型数据；`card/CodexHelper` = 图鉴解锁。
- `util/CardNbt` = 卡牌 NBT（owner/glint/唯一编号/日期/胜次）。

### client（客户端渲染/UI，集中在此）
- `CardPouchScreen` = 卡袋 GUI（generic_54 两段 blit）。
- `DeckBoxScreen` = 卡组匣 GUI（generic_54 两段 blit，8×2 卡组）。
- `CardExchangeScreen` = 交换台 GUI；`DuelTableScreen` = 登记 GUI；`DuelHostSetupScreen` = 主机设置。
- `DuelScreen` = 对局主 UI（渲染/动画/交互都在这）；`DuelView` = 对局状态视图；`DuelEmoji` = 程序化表情。
- `CollectionAlbumScreen` = 收藏册 GUI。
- `InspectAnimator` = 端详动画；`InspectNameHud` = 端详名牌；`PackOpenAnimator` = 开包动画。
- `ClientSetup` = 注册 MenuScreens / ItemProperties predicate；`LaiguConfigScreen` = mod 配置屏。

### config
- `LaiguConfig` = mod 配置（如积分动画速度倍率）。

### container（菜单容器）
- `CardPouchContainer/Menu` = 卡袋（27 格 3×9）。
- `DeckBoxContainer/Menu` = 卡组匣（16 格 8×2，确认构建）。
- `CardExchangeMenu` = 交换台菜单；`DuelTableMenu` = 登记菜单。

### duel（对局核心，纯逻辑）
- `DuelGame` = 对局状态机（纯逻辑无 MC 依赖）。
- `ScoreEngine` = 计分/结算引擎（含金卡第二 switch）。
- `EffectType` = 触发效果类型；`DuelCardData` = 单卡数据（效果/金卡特效）；`FieldCard` = 场上卡（含 roundsOnField）。
- `DuelCardCatalog` = 文物 id ↔ 对战效果的索引表（效果归谁在此改）。
- `DuelAi` = 人机；`DuelActions` = 操作码/协议常量；`CardClass` = 职业枚举。

### event
- `ModEvents` = FORGE 总线事件（Capability 挂载、玩家 tick 羁绊、离线检测等）。

### item
- `CardItem` = 来古牌物品；`CardPackItem` = 4 种卡包；`CardPouchItem` = 卡袋；`DeckBoxItem` = 卡组匣；`CollectionAlbumItem` = 收藏册。

### network（网络包，注册于 ModPackets）
- `ModPackets` = SimpleChannel 注册与 nextId。
- `PackOpenEffectPacket`、`DuelStateS2CPacket`、`DuelActionC2SPacket`、`DuelEmojiS2CPacket`、`CollectionAlbum*`。

### registry
- `ModItems / ModBlocks / ModBlockEntities / ModMenuTypes / ModCreativeTabs` = 各注册表。

## 四、regenerate（重新生成索引）

包结构变了再跑一遍底部命令刷新；新增/删除文件后把上面对应的文件名补/删。想偷懒可让 agent 按此段重列。

```powershell
$root="D:\GuguFiles\AI测试项目\MC卡牌游戏开发\Laigu\src\main\java\com\laigu\laigu"
Get-ChildItem -Path $root -Recurse -Filter *.java |
  ForEach-Object { $_.FullName.Substring($root.Length+1) } | Sort-Object
```

# 来古牌 · 对战卡池 30 张（V1 原型）

> 本文件定义 PvP 原型的第一批 30 张对战卡。效果写在卡牌描述（tooltip）上。
> 计分公式：**最终分 = 基础分 × 倍率 + 额外分**（详见 `对战玩法-设计.md` §4.5）。
> 反制类词条 V1 不做。

---

## 1. 卡牌结构

| 字段 | 说明 |
|---|---|
| 职业 | 攻·炽 / 守·衡 / 谋·策 / 鼎·盛（战斗职责） |
| 稀有度 | 普通 / 金质（金质数值升档，供「盛世」等计数） |
| 朝代 | 与收集卡一致的朝代标签，供「敕令」（秦代计数）等条件使用 |
| 效果 | 每卡一句效果文本，结算时被动生效 |

## 2. 关键词速查

- **【消耗】**：结算后该卡移除出游戏（对局副本），槽位空置不填补。
- **骰型条件**：检查你本轮选到的骰面组合——顺子（互不相同且连续，≥3 颗）、全奇、全偶、全大(≥4)、全小(≤3)、含 1。
- **朝代条件**：统计你"场上 + 手牌"中某朝代的卡数。
- **位置条件**：两侧 / 相邻槽位（空位不算相邻）。
- **上轮在场**：该卡上一轮结算时仍在场上。

## 4. 原型实现约定（V1 待实测调参）

1. 卡组 = 卡组匣（10 张，同职业 ≤5）。登记对战时**复制**卡组，不消耗本体。
2. 布局骰子必须全部布置；场上无卡（全消耗）时允许跳过布置。
3. 顺子 = 骰面互不相同且连续，要求 ≥3 颗骰。
4. 朝代/职业/金质计数范围 = 场上 + 手牌。
5. 倍率下限 1、基础分下限 0。
6. 原型对局：单对战方块双人，或与 AI 对战；三局两胜，加赛轮容量 4。

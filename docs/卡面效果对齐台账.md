# 卡面效果对齐台账（依据 卡牌效果清单.md，2026-09-03）

> 清单为唯一权威。原则：金卡 = 主效果 + 焕章（独立于白卡实现）；描述与行为均以清单为准。
> 用户拍板：鲁王金主效果 = 2×x（第七节）；号角额外分归我方；描金壶焕章「当前基础分」= 发动时我方当前基础分（非最终）；
> 溪山金「激活所有卡牌」= 仅己方，无激活词条的卡尝试即失败。

## 一、行为差异（需改代码）

## 二、口径记录
- 充能x=每颗骰分别触发一次（结算时按骰数触发）；充能N=至少N颗骰触发一次。
- 「激活N」触发语义（2026-09-03 实机对账后用户拍板=维持）：每累计 N 次激活触发一次，可重复（触发后进度清零重计）。溪山金 5 骰喂千里江山金 10 次激活 → 一回合触发 5 次。激活进度每轮清零；旧引擎对照侧奖励被禁，对照差异属预期。
- 生产桥接修复（同日）：结算钩子曾把旧引擎 FieldCard.activation 回灌新核心，导致同一激活源被新旧双算、阈值卡倍率爆炸（旧1 vs 新19/21）；已改为每轮统一清零，激活进度由新核心独立累计。
- 激活倍率展示双算（同日，暂缓）：展示分 = 新核心结果 + 旧引擎 timing 计数器，旧 activateCard 路径的激活奖励仍在写 timing → 展示倍率偏高（实证 3→5）。尝试停写旧 timing 两次均破坏右侧积分栏/动画（展示数据源被掐断），按用户拍板**暂时接受双算显示**；根治=改造展示层直接吃新核心步骤/弹窗事件（待办）。
- 「尝试激活失败」：对无激活词条（无 OnActivation 或阈值0）的卡不累计激活进度，仅计数失败（供海错金焕章）。
- 万工轿回合切换：奇数轮看奇数骰、偶数轮看偶数骰；金焕章视骰使全部己方骰按当轮模式计。
- 顺子间隔1：去重排序后相邻差全为1、恰允许一处差2（≥3颗）。
- 观星金焕章按「每消耗1点行动力+15」计（消耗事件≈消耗点数）。
- 江山金焕章含自身被激活（每次激活事件+5）。

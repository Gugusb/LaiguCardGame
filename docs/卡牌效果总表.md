# 卡牌效果总表（平衡性调整用）

> 数据源：`src/main/java/com/laigu/laigu/duel/DuelCardCatalog.java`（效果连接表）。
> 改数值直接改该文件对应行的 p1/p2/charge/描述。
>
> **金卡规则说明**（实现以 `DuelCardData.java` 为准）：金卡主效果在卡牌数据构建时生成独立的最终参数；结算时不再对主效果或焕章做隐式二次翻倍。奖励参数通常翻倍，阈值、抽卡/AP 数量、次数、标志和目标筛选保持原值；每张卡的实际配置以 `DuelCardCatalog.java` 为准。
>
> **战场规则**：5 槽位 · 牌库 16 张 · 大比分抢二（封顶 5 轮，净胜分定胜负）· 共享骰池 10 颗 · 持骰上限 8 · 先手抓 3 次/后手 2 次 · 手牌上限 8
>
> 同一文物 id 可出现在多个效果条目（如「浑天仪」既是抢骰卡也是激活触发卡），以游戏内登记到卡组的那份为准。

## 十、平衡性速查备忘

- **改数值**：修改 `DuelCardCatalog.java` 中普通主效果参数；金卡最终主参数由 `DuelCardData` 在构建时生成，结算阶段不再隐式翻倍。
- **改焕章**：使用卡牌的独立焕章字段，并明确触发窗口；焕章最终值只缩放一次。
- **改激活/焕章逻辑**：`DuelGame.java` 结算段（`resolveAmbush` / `fireActivate` / `activateCard` / 浑天顺子段 / 朝代联动段）。
- **改全局规则**：`DuelGame.java` 顶部常量（FIELD_SLOTS=5、MAX_ROUNDS=5、SHARED_POOL_SIZE=10、MAX_DICE_HELD=8、FIRST/SECOND_DRAFT_TURNS=3/2、MAX_HAND=8）
- **胜负**：大比分抢二（先到 2 胜），5 轮未拉开按净胜分

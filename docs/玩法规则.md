# 来古牌（Laigu）· 玩法规则

> 本文档整理「来古牌」模组的完整玩法规则，供玩家与后续开发参考。
> 以已上线实现为准；数值为初版，实测后可能调整（标注处）。

---

## 一、总览

来古牌是服务器后期的收集 + 卡牌对战玩法模组。核心目标：

1. **收集**：开卡包、交换、图鉴集齐，作为神装收集完之后的长期目标。
2. **对战**：用收集到的来古牌组卡组，与人（或 AI）在「共享骰池」规则下对战决胜负，可开启「黑暗对决」真夺卡。

---

## 二、卡牌与稀有度

- **卡牌本体**：79 张中国（及部分世界）文物主题来古牌，每张有唯一物品。
- **稀有度**：每张卡有 **普通（common）** 与 **金质（gold）** 两版，共 158 张卡牌物品。普通/金质是**不同物品**，算两张不同卡。
- **卡牌属性**：朝代、文物类型（用于图鉴/收集标签）、卡面贴图、效果（对战内，见 §5）。
- **卡牌实例**：每张开包/交换产出的卡有**唯一编号 + 获得日期**；在对局胜场中实际部署过的卡会累积「参战胜次数」（显示于 tooltip）。
- **堆叠**：卡牌不可堆叠，每格一张。
- **卡包**（4 种）：普通卡包、末影卡包、炫彩卡包、金质卡包。右键开包随机出卡，普通 99.8% / 金质 0.2%，任意版本 1% 附魔光泽，并署名所有者。

## 三、收集系统

### 3.1 卡袋（存储工具）
- 右键卡袋打开 **27 格（3×9）** 窗口，**只能放来古牌**。
- 内容存于卡袋物品 NBT，随身带、随时存取。
- 副手持卡袋可触发**羁绊**（buff，见 §5.6）。

### 3.2 图鉴（Capability 解锁）
- 每名玩家自动记录已获得（且署名本人）的卡牌。
- 首次获得某卡自动解锁并提示。

### 3.3 交换台
- 卡片交换台：双方各放一张卡到 A/B 侧，互相确认后交换，并解锁各自图鉴。
- 换卡会改写卡牌所属（署名），换到的卡归你。

### 3.4 收藏册
- 右键打开左右双页：左页 = 图鉴，右页 = 选中卡详情（放大图 + 编号/日期/胜次等）。
- 空槽放卡、点击已收集槽取回；可跳朝代、集齐朝代标记。

### 3.5 获取途径（规划/可扩展）
- 计划接入：Boss 掉落、结构战利品、考古、钓鱼、村民交易、刷怪塔。
- **当前**：创造模式页签获取（免去随机性，便于测试/体验）。

---

## 四、卡组

- **卡组匣**：右键打开 **16 格（8×2）** 卡组区 + 玩家背包。
- **只能放来古牌**；每格一张。
- 点「**确认构建**」统一校验：**必须 16 张、无重复卡、全部为有效对战卡**；合法则整卡组标绿、能参与对战；不合法对应槽位标红。
- 登记时**复制**卡组，**不消耗**本体；卡牌 NBT（如附魔光泽）全部保留。
- 只有「已构建」的卡组可以登记对战。

## 五、对局规则

### 5.1 总则
- **双人对战（PvP）或人机（AI）**：登记卡组（各 16 张）→ 主机设置 → 开局。
- 对局每轮独立结算，**三局（有限）**，规则见 5.5（抢二胜制已取代单纯三局两胜）。

### 5.2 每轮流程
1. **部署**：每回合 **行动力 2 点**。可放置卡牌到场上任意槽位，或替换已有卡（替换弃置原卡）；「从无到有」也是替换。
2. **揭示**：双方都确认部署后，本轮回新增卡翻牌（部署阶段双方互不可见，确认后揭示）。
3. **共享骰池抢骰**：系统掷出共享骰子，双方按**固定抓取计划**轮流抓：
   - 先手 **1/2/1**（共 3 次），后手 **2/2**（共 2 次）；默认后手 4 颗、池剩 2 颗。
   - 抓取次数可被「抓取系」效果增减；骰池取空即止。
   - **未布置的骰子继承到下一回合**；骰池上限 8。
4. **布置**：把抓到的骰子放到场上卡（每卡上限 2 颗），可取下换位置；确认后进入结算。
5. **结算**：按 5.3 计分 → 比大小定本轮胜负 → 进入下一轮（分数清零）。

### 5.3 计分公式
```
最终分 = 基础分 × 倍率 + 额外分
```
- **基础分** = 你所有已布置骰面之和 + 基础分加成（下限 0）。
- **倍率** = 1 + 倍率加成（下限 1）。
- **额外分** = 额外分加成（不吃倍率）。
- 所有卡牌效果**只在结算阶段判定**；部署/揭示/抢骰/布置不改数值。
- 结算只发生在**布置**的骰子上；未布置骰不计分、继承下轮。

### 5.4 效果体系（按职业）
四职业：**攻·炽**（吃骰输出）、**守·衡**（不吃骰保底）、**谋·策**（条件/位置）、**鼎·盛**（基础/倍率引擎）。
- 效果只做三件事之一：加**基础分**、加**倍率**、加**额外分**。
- 关键词：【充能】(有骰才生效，可重复)、【消耗】(结算后移除)、骰型条件（顺子/全奇/全偶/全大等）、朝代/职业计数、位置条件、每有 X 线性叠加。

### 5.5 胜负 —— **抢二胜制**
- **先拿 2 个本轮胜者**获胜（2:0 / 3:1 / 5:3 等）。
- 若打到第 5 轮仍未拉开（净胜 < 2），按**累计总分**判最终胜者；平分则加赛。
- 认输/退出 = 判负。

### 5.6 金卡规则
- **金卡数值 = 白卡 × 2**，效果升档/更强。
- **金卡不能直接上场**：只能替换场上同名白卡（升级）。
- 金卡有**专属金卡特效**（进阶效果），并在场上持续散发金色粒子。
- 某些计数/缩放类效果分普通/金质不同处理。

### 5.7 触发能力
部分卡有**触发**效果，在事件点结算：入场、离场、回合开始、回合结束、使用其他手牌等（如抽卡、回行动力）。服务端统一结算，双人/AI 一致。

### 5.8 黑暗对决（真夺卡）
- 主机设置中可开启。**开启后只要分出胜负（含认输/逃跑），胜者就从败者卡组随机夺走一张**，署名改胜者，交给胜者（若胜者 = AI 则卡掉落在对战桌旁）。
- 这是让卡组「少一张」的唯一途径；被夺后卡组匣同步减少一张。

### 5.9 观战 & 表情
- 对决开始后，未登记路人右键对战方块即加入**观战**（实时看双方操作，无法操作，可随时退出）。
- 对局内可发**表情**（8 个），双方与观战者都能看到气泡。

### 5.10 血量 / 防破坏
- 对战中**无 HP**，纯比分数。
- 对战方块防爆、不可破坏；被不可抗力移除则对局作废，登记卡组副本返还玩家。

## 六、公共规则 / 判定细节

- **顺子**：所有已布置骰面互不相同且连续（≥3 颗才算顺子；2 颗不算）。
- **计数范围**：朝代/职业/金质计数**只算场上卡**（除非效果明确说明）。
- **手牌**：不设上限；第 1 轮抽 4 选 2，之后每轮 1；可被效果额外抽牌。
- **行动力**：每回合 2 点；**第 n 轮上限 = min(第 n 轮, 4)**，逐轮递增。
- **AI**：当前为简单流程 AI（贪大面/凑条件/布置），强度弱，适合练手。

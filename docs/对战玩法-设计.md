# 来古牌 · 卡牌对战玩法设计（共享骰池版）

> 现状：`模组说明.md` 所述收集系统（开包/卡袋/图鉴/交换台）已落地。本文定义其上的对抗玩法。
> 参考：小丑牌（Balatro）的评分引擎思路 + 共享骰池（公共池轮选）博弈。
> 环境：Minecraft 1.20.1 + Forge 47.4.6 + JDK 17。
> 文档状态：**V1 定稿，待审**。V1 = 暗置部署 + 共享骰池 + 条件词条 + 双人 PvP + 人机。
>
> **实现说明（2026-08-13）**：本文为设计稿；已落地实现按 `对战-Q&A.md` 的 A 答案调整，关键差异——
> 对战卡直接用来古牌（文物牌，效果经索引映射，独立于卡牌本体）；每回合 2 行动力、可替换任意槽位（替换弃置）；手牌不设上限；
> 骰子只算放置的计分、未布置骰继承下轮；抢骰改为「固定抓取计划」——先手 1/2/1 共 3 次、后手 2/2 共 2 次（默认各 4 颗），
> 并新增「抓取系」效果可改双方抓取次数 / 系统掷骰 +N；
> 登记改为「打开 UI 放满 10 张点确定」，第一个确认者为主机、可设黑暗对决（胜者真抢夺败者一张卡，署名改胜者）；
> 金质暂无专属效果；AI 仅保证流程正确。

---

## 1. 设计目标与约束

- **学习成本低**：规则一句话——"暗着摆卡 → 一起亮 → 轮流抢骰 → 摆骰 → 算分比大小"。
- **有深度**：深度在**抢骰博弈**（公共池轮选）、**组卡**（效果引擎组合）、**骰型取舍**（为凑顺子/全奇而选面）。
- **全部卡有意义**：158 张各有得分效果，都能进卡组、都能打得分引擎。
- **克制引入**：唯一新增资源 = 骰子（公共池，无重投）。新资产只有 2 物品 + 1 方块（卡组匣、骰子、对战方块）。

## 2. 卡牌结构

| 字段 | 说明 |
|---|---|
| **职业** | **攻·炽 / 守·衡 / 谋·策 / 鼎·盛**（战斗职责，与文物类型无关） |
| **得分效果** | 每张卡一个「效果文本」，158 张不重复；效果取自职业对应模板（§3.3） |
| **稀有度** | 普通 = 简单效果；金质 = 效果数值 +1 或乘算/条件升档 |
| **朝代 / 文物类型** | 纯收集/图鉴标签；**对局内羁绊 V1 不做**（V2 可选） |

> 效果数值来源：词汇表（§3）+ 每卡一组「效果×数值」。金质修正 = 数值 +1 或效果升档。

## 3. 职业体系与效果词汇表 v1

### 3.1 四职业（战斗职责）

| 职业 | 职责 | 卡组定位 | 主要分数杠杆 |
|---|---|---|---|
| **攻·炽** | 吃骰输出 | 主力得分，抢骰刚需 | 骰子驱动的倍率 / 额外分 |
| **守·衡** | 稳定保底 | 不吃骰兜底 | 无条件额外分 / 低骰 |
| **谋·策** | 条件 / 位置收益 | 骰型·朝代·两侧条件 | 条件触发的倍率 / 额外分 |
| **鼎·盛** | 基础 / 倍率引擎 | 后期放大器 | 基础分加成 / 倍率 |

> 反制类效果（封锁/扣分/偷分等）**V1 暂缓**，V2 再议；V1 聚焦「如何把自己的分数打高」。

### 3.2 组卡约束

10 张卡组中**同一职业最多 5 张**——强制混编，逼玩家收集各职业卡。

### 3.3 计分与效果词汇表（三杠杆 + 关键词）

**计分公式**（详见 §4.5）：

```
最终分 = 基础分 × 倍率 + 额外分
```

卡牌效果只做三件事之一（三杠杆）：

| 杠杆 | 计算 | 价值 | 典型模板 |
|---|---|---|---|
| **基础分** | Σ骰面 + 基础分加成 | **最贵**（会被倍率放大） | 每张秦代卡 +2 基础分 |
| **倍率** | 1 + 倍率加成（min 1） | 放大器 | 本卡每骰 +1 倍率 |
| **额外分** | 直接加分（不吃倍率） | 保底 | 本卡每骰 +10 额外分 |

> **构筑核心**：基础分加成会被倍率放大——"基础分引擎 × 倍率引擎"是 1+1>2 的主要来源。

**关键词**：

| 关键词 | 定义 |
|---|---|
| **【消耗】** | 结算后移除出游戏；槽位空置不填补，相邻/对位关系不变 |
| **骰型条件** | 检查你选到的骰面组合：顺子（互不相同且连续）、全奇、全偶、全大(≥4)、全小(≤3)、含 1 / 含 6 等 |
| **朝代条件** | 统计你拥有的某朝代卡数（场上 + 手牌，范围可调） |
| **位置条件** | 两侧 / 相邻槽位的卡牌情况（空位不计） |
| **每有 X** | 按 X 的数量线性叠加（每骰 / 每张某朝卡 / 每张某职业卡） |

**效果模板（按职业，数值均可调）**：

**攻·炽**（吃骰 → 倍率 / 额外）

| 模板 | 定位 |
|---|---|
| 本卡每有 1 颗骰 → +10 额外分 | 吃骰·额外（种子 A） |
| 【消耗】若你的骰为顺子，本卡每有 1 颗骰 → +1 倍率 | 吃骰·倍率（种子 B） |
| 本卡每有 1 颗骰 → +3 基础分 | 吃骰·基础（最贵） |
| 本卡骰子 ≥2 颗 → +15 额外分 | 堆叠奖励 |

**守·衡**（保底 → 额外）

| 模板 | 定位 |
|---|---|
| 无条件 +3 额外分 | 不吃骰保底 |
| 本卡骰子为 0 → +2 额外分 | 鼓励不喂骰 |
| 你的骰含 1 → +2 额外分 | 捡漏 |

**谋·策**（条件 / 位置 → 倍率 / 额外）

| 模板 | 定位 |
|---|---|
| 两侧均非本卡朝代 → +1 倍率 +20 额外分 | 位置·孤立（种子 D） |
| 若你的骰为顺子 → +2 倍率 | 骰型·倍率 |
| 若你的骰全大（≥4）→ +15 额外分 | 骰型·额外 |
| 相邻（左/右）有卡 → +2 倍率 | 位置·相邻 |
| 【消耗】结算时 → +30 额外分 | 一次性炸弹 |

**鼎·盛**（基础 / 倍率引擎）

| 模板 | 定位 |
|---|---|
| 我方每有 1 张秦代卡 → +2 基础分 | 朝代·基础（种子 C） |
| 我方每有 1 张鼎·盛卡 → +1 倍率 | 职业·倍率 |
| 上轮也在场上 → +5 额外分 | 跨轮·保底 |
| 【消耗】结算时 → 本轮基础分 ×2 | 一次性翻倍 |

## 4. 对局规则（共享骰池制）

### 4.1 开局

- 卡组 **10 张**，**同一职业最多 5 张**；起手抽 **4 张**，选 **2 张**暗置上场（其余 2 张留手）。
- 场上容量：第 1 / 2 / 3 轮 = **2 / 3 / 4**。
- 每方 **无 HP**——纯比分数，每轮结算后**分数清零**，赛制**三局两胜**。

### 4.2 每轮流程（5 步）

1. **暗置部署**：抽 1 张 → 向场上补位（空槽）或换牌（1:1 换下场上某张）；新增的卡**卡面朝下**（第 2/3 轮只有新卡是暗的，旧卡双方已知）。
2. **同时揭示**：双方翻开本轮回新增的卡——**仅信息同步**，不结算任何效果；所有效果统一在计分阶段（§4.5）判定。
3. **共享骰池**：系统一次掷 **10 颗**骰子，双方**轮流选取**。选骰数 = 你的场上容量（2/3/4）；**上一轮输者先选**（第 1 轮掷骰定）；选到的骰进自己的骰池；**池空即止**。**选骰阶段不触发、不结算、不修改任何效果**（骰面始终保持原值，不中途改值）。
4. **布置**：把骰池中的骰分配到场上卡，**每卡上限 2 颗**。**布置阶段同样不结算效果**；骰子分布在此定格，供计分时条件判断。
5. **结算**：按 §4.5 计分——**最终分 = 基础分 × 倍率 + 额外分** → 比较双方分数，**大者赢本轮**（记 1 分，进下一轮时分数清零）。同分 = 本轮无人得分。

### 4.3 胜负

- 三局两胜：先拿 **2 个本轮胜**者赢。第 3 轮后仍 1:1 → 加赛 1 轮（规则同第 3 轮，容量 4）。
- 对局中退出 = 判负。

### 4.4 深度来源

1. **抢骰**：公共池轮选——拿大面给自己，还是抢走对手骰型卡要的奇/偶/顺子面。核心博弈。
2. **组卡**：10 张里搭引擎（基础分 / 倍率 / 额外分三杠杆取舍 + 骰型/朝代/位置条件），受**同职业 ≤5 张**约束。
3. **布置取舍**：每卡 ≤2 骰，把骰子喂给吃骰引擎（每骰倍率/额外），还是让它只贡献基础分。
4. **骰型博弈**：要不要为凑顺子/全奇放弃 6 面——骰型条件卡的高风险高回报。

### 4.5 计分事件与结算顺序（重要）

**计分公式**：

```
最终分 = 基础分 × 倍率 + 额外分
```

| 分量 | 计算 | 说明 |
|---|---|---|
| **基础分** | Σ你选到的骰面 + Σ基础分加成 | 下限 0 |
| **倍率** | 1 + Σ倍率加成 | 下限 1 |
| **额外分** | Σ额外分加成 | 不吃倍率，纯保底 |

**设计原则（核心）**：
1. **只有计分阶段结算效果**。部署 / 揭示 / 选骰 / 布置阶段均不触发、不结算、不修改任何数值——防止中途改值 / 中途触发造成错乱与歧义。
2. **揭示 = 仅信息同步**：双方亮牌，不结算任何效果。
3. **选骰 / 布置只记录数据**：选骰数、骰面、布置分布在此定格，供计分时条件判断。
4. **所有效果 = 「结算时条件判定」**：加基础分 / 加倍率 / 加额外分 / 【消耗】，全部被动、无目标、无中断。
5. **基础分加成会被倍率放大**（最贵词条）；额外分不吃倍率（保底）。这是构筑深度的来源。
6. 双方独立结算后比大小；结果**确定、无歧义、可预测**。

**结算管线（计分阶段内，按序）**：

| 顺序 | 检查点 | 作用 |
|---|---|---|
| 1 | **采集数据** | 你的骰面集合、每卡骰子分布、朝代/职业计数（已在选骰/布置定格） |
| 2 | **基础分** | Σ骰面 + Σ基础分加成（下限 0） |
| 3 | **倍率** | 1 + Σ倍率加成（下限 1） |
| 4 | **额外分** | Σ额外分加成 |
| 5 | **最终分** | 基础分 × 倍率 + 额外分；【消耗】卡标记移除（结算后出局） |
| 6 | **比大小** | 大者赢本轮 |

**关键规则**：
1. **倍率下限 1、基础分下限 0**，防止负数 / 归零歧义。
2. **【消耗】** 结算后移除出游戏：槽位空置不填补，相邻 / 对位关系保持（空位不计）。
3. **骰型条件**（顺子等）检查"你选到的骰面"；**顺子 = 骰面互不相同且连续，要求 ≥3 颗骰**（2 骰太容易），可调。
4. **朝代条件**统计"场上 + 手牌"（你拥有的卡），范围可调。
5. **所有选到的骰必须布置**（每卡 ≤2；选骰数 = 场上容量，必然放得下）——不存在"未布置骰"。
6. **V1 不开放「选骰中途」/「布置中途」触发**——任何效果不得在计分前修改骰面、选骰数、场上状态；需这类效果的留 V2（并配套中断 UI）。

## 6. 对战方块与 GUI

- **对战方块** `laigu:duel_table`：双人对战盘。
- **GUI 布局**：中央 = 共享骰池区（10 颗骰面 + 选骰指针 + 本回合状态）；两侧 = 各自手牌 + 场上槽位（暗置/揭示状态）+ 骰池分配区；顶部 = 双方本轮得分 + 总局比分；底部 = 阶段按钮。
- **流程**：双方登记卡组 → 双方点「开始」→ 轮流执行 5 步 → 每轮结算 → 胜负横幅 + 再来一局。
- **防呆**：只能操作自己的手牌/卡组/骰池；对方操作时本侧只读；暗置阶段对方不可见。
- **持久化**：对局状态存方块 NBT，重启不丢（同交换台）。

### 6.1 方块实体状态机

```
REGISTER → DEPLOY(暗置) → REVEAL(揭示+信息同步) → DRAFT(抢骰)
→ PLACE(布置) → SCORE(结算) → ROUND_END → [下一轮 DEPLOY …] → FINISHED
```

### 6.2 网络包（`ModPackets` 新增，`nextId++`）

| 方向 | 包 | 内容 |
|---|---|---|
| C→S | `StartDuelPacket` / `DeployCardPacket` / `RevealConfirmPacket` / `PickDiePacket` / `PlaceDiePacket` | 对局操作 |
| S→C | `DuelStatePacket` | 全量同步：场上/骰池/得分/阶段/轮次/比分（手牌只发持有者；暗置卡只发持有者） |

## 7. 人机 AI（V1 含）

简单规则，用于单人自测：
- 部署：优先放自己效果最值的卡（倍率卡 → 吃骰卡 → 基础分卡）。
- 抢骰：优先大面；若自己有骰型卡（顺子/全奇等），优先凑对应面。
- 布置：把大面给"每骰倍率/额外"类卡，低面留给基础分词条卡。

## 8. 收集 ↔ 对战闭环

| 拉力 | 机制 |
|---|---|
| 想赢 → 想要好效果卡 | 效果引擎决定强度 |
| 金质更强 | 数值 +1 / 乘算 / 条件升档 |
| 收集全效果类型 | 基础分/倍率/额外分三杠杆要配齐才有上限 |
| 职业定向收集 | 想组攻卡组 → 定向收集攻职业卡；金质职业卡是各职业天花板 |
| 图鉴挂钩（V2） | 集齐某职业/某类效果解锁传说卡；对战胜场解锁图鉴奖励 |

# 来古牌（Laigu）· 联机测试流程

> 给测试用的标准化操作索引。想测试时照流程走，不用再想步骤。

## 一、一条命令拉起双客户端

在项目根目录（`D:\GuguFiles\AI测试项目\MC卡牌游戏开发\Laigu\`）执行：

```powershell
.\tools\test_client.ps1 dual
```

脚本自动（每次启动前自愈已知坑，无需再管）：
- 删除 `run-client2\mods\laigu-dev.jar`（残留旧 jar 会导致注册表握手失败）；
- 把 `run\saves\`、`run-client2\saves\` 里的旧世界移进各自的 `saves_archive\`（旧档注册表错位坑）；
- 并发拉起两个客户端：**主机**（gameDir=`run/`，名 Dev）、**客机**（gameDir=`run-client2/`，名 Player2）。

日志：`run-host.log`（主机） / `run-slave.log`（客机）。想单独起一个就 `... host` 或 `... slave`。

## 二、进联机的游戏内步骤（主机手动）

两个窗口都到主菜单后：

1. 主机进一个世界 → 按 ESC 暂停。
2. 「对局域网开放」→「允许作弊：开」。
3. 客机「多人游戏」→ 直接连 `localhost:25565`（或 LAN 列表里的主机）。

> 世界直接用创造页签拿来古牌（对局卡组匣/来古牌/卡包等只在创造页签获取，`/gamemode creative`）。

## 三、清理/停止

- 两个客户端分别点「退出世界」+ 关窗口即可关进程；`dual` 用完可直接关，不残留常驻进程。
- 想只重置环境（不做启动）可用 `.\tools\test_client.ps1 clean`。

## 四、重置对局房间

对局相关（对战方块登记/AI/观战）都在方块内：破坏对战方块（不可抗力）会自动作废对局并返还登记卡组副本、踢出观战者。重新登记即可开新局，无需重启客户端。

## 五、注意（沿用交接文档）

- 勿加载旧存档（本脚本已自动隔离）；勿让 `run-client2\mods\laigu-dev.jar` 残留（已自动删）。
- 客户端方向网络包用 `unsafeRunWhenOn(Dist.CLIENT,...)`，别用 `safeRunWhenOn`（会误报 FATAL 且动画不播）。
